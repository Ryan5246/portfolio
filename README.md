# Ryan Priyank Sunjai Dhas Portfolio

A responsive, dependency free personal portfolio built with HTML, CSS and JavaScript. It covers Ryan's software, robotics, computer vision and embedded electronics experience, including his work with PneuRelief's electrical team.

## Preview locally

From the repository root, run:

```powershell
python -m http.server 4173
```

Then open `http://127.0.0.1:4173`.

## Customisation

- Update portfolio content in `index.html`.
- Adjust colours and layout tokens at the top of `styles.css`.
- Add public repository links only where code can be shared safely.
- Keep internship code, employer data, credentials and API keys private.

## Deployment

The folder can be deployed directly to GitHub Pages, Netlify, Vercel or any static web host.
